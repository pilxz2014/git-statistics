# Git 提交统计工具 — 需求文档

> 版本：v0.4（需求草案） · 状态：待评审 · 更新：2026-09-29

---

## 1. 项目概述

### 1.1 一句话定位
右键一个带 `.git` 的工程项目 → 点击「Git 提交统计」→ 自动采集仓库提交数据 → 生成一个**可离线打开、可动态筛选**的 HTML 报告，从**提交次数**和**代码行数**两条主线直观呈现团队/个人的活跃与贡献。

### 1.2 核心目标
- **零依赖使用**：普通开发者在 Windows 上通过右键菜单即可完成，无需命令行、无需额外服务。
- **开箱即看的报告**：生成单个 HTML 文件，双击即开、无需联网、无需服务器。
- **双统计口径**：不止数「提了多少次」，更数「改了多少行代码」，两者可一键切换查看。
- **分支维度**：统计前预选单分支，报告标注统计分支并提供仓库分支清单作参考（不支持切换）。
- **分类清晰 + 动态筛选**：报告按 Tab 分类展示；全局筛选器（时间 / 人员 / 类型 / 关键字）联动所有图表。

### 1.3 目标用户
- 团队负责人 / 项目经理：了解团队产出、活跃度、代码贡献。
- 个人开发者：回顾工作节奏与代码贡献分布。
- 开源维护者：对外展示项目活跃度。

## 2. 使用场景

```
资源管理器中右键工程目录（含 .git）
   │
   ▼ 点击「Git 提交统计」→ 选择要统计的分支（默认当前分支）
后台采集：仅统计所选分支 git log <branch> --numstat → commits.json
   │
   ▼ 注入模板
生成 git-statistics-report.html（自动在浏览器打开）
   │
   ▼ 用户按 Tab 查看，用口径 / 时间 / 人员 / 类型筛选下钻（分支不可切换）
```

## 3. 功能需求

### 3.1 触发与集成（右键菜单）
- **FR-1**：右键**文件夹**出现「Git 提交统计」菜单项。
- **FR-2**：点击后校验 `.git`：存在则采集；不存在则友好提示「该目录不是 Git 仓库」。
- **FR-3**：生成完成后自动在浏览器打开报告。
- **FR-4**：提供「安装 / 卸载」脚本（注册表 `HKEY_CLASSES_ROOT\Directory\shell\` 的注册与清理）。
- **FR-4b**：生成前选择要统计的分支（脚本列出本地分支，默认当前分支；支持 `--branch <name>` 参数）。分支在报告中仅作标注与清单参考，不可切换。

> 取舍：标准注册表项无法基于 `.git` 是否存在做条件显示，v1 采用「目录上始终显示、脚本内判断」；进阶换编译型 Shell Extension（v2）。

### 3.2 数据采集
输出统一 `commits.json`，每条提交：

| 字段 | 说明 |
|---|---|
| `hash` | 提交短哈希 |
| `author` / `email` | 作者 姓名 / 邮箱 |
| `when` | 提交时间（author 时间，ISO） |
| `subject` | 提交信息首行 |
| `additions` / `deletions` | 新增 / 删除行数 |
| `files` | 变更文件路径列表 |
| `file_ext` | 变更文件扩展名集合（去重） |

建议命令（`--numstat` 一份输出同时拿到文件与行数）：

```bash
git log <branch> --date=iso --pretty=format:'%h%x1f%an%x1f%ae%x1f%ad%x1f%s' --numstat
```

- **FR-5**：必须预选单分支统计（默认当前分支，支持 `--branch <name>`）；不做 `--all` 全分支重扫。
- **FR-6**：大仓库采集有进度提示，避免「无响应」观感。

分支清单（轻量参考信息，不做全量 numstat）：

```bash
git for-each-ref --format='%(refname:short)' refs/heads
git rev-list --count <branch>                         # 各分支提交数
git rev-list --left-right --count main...<branch>     # 领先 / 落后 main
```

> 分支清单用轻量命令采集（每分支仅名称 / 提交数 / 最后提交 / 领先落后）；作者、行数等重统计只针对所选单分支，避免全分支慢扫。

### 3.3 统计维度（核心）

**统计口径定义**（贯穿全文）：

| 口径 | 含义 | 说明 |
|---|---|---|
| 提交次数 | 单次提交计 1 | 判断活跃度 |
| 改动行数 | 新增 + 删除 | 判断工作量/改动量 |
| 净增行数 | 新增 − 删除 | 判断代码净增长 |

> 界面提供全局「统计口径」切换：**提交次数 ↔ 代码行数**，多数图表随口径重算；行数相关的专用图表始终以行为单位。

维度按 Tab 分类如下（★ v1 必做；其余 v2）：

#### A. 总览（Overview）
- ★ 总提交、贡献者数、活跃天数
- ★ 新增 / 删除 / 净增 行数（KPI 与摘要）
- ★ 提交 / 改动趋势折线（随口径切换，日/周/月自适应粒度）
- ★ 提交热力图（GitHub 风格日历，按次数）

#### B. 时间（When）
- ★ 星期分布（周一~周日，随口径：次数或行数）
- ★ 小时分布（0–23 点，随口径）
- 增删行数随时间趋势（并入总览 / 代码行数 Tab）

#### C. 人员（Who）
- ★ 人员排行表：作者 · 提交数 · 改动行数 · 新增 · 删除 · 净增 · 变更文件 · 活跃天数（**可排序**）
- ★ 贡献占比环形图（随口径）
- ★ 人员贡献趋势（多人按月堆叠，随口径）
- 每人首末提交与持续活跃时长（v2）

#### D. 分支（Branch，仅参考）
- ★ 报告明确标注「当前统计分支」
- ★ 仓库分支清单：分支名 · 是否当前 · 提交数 · 最后提交 · 领先 / 落后 main（**可排序，参考用**）
- 分支 ahead/behind、合并关系等可在清单基础上扩展（v2）

#### E. 代码行数（Lines）★ 独立强化
- ★ 净增行数趋势（可正可负的折线）
- ★ 文件类型（扩展名）增删行数堆叠柱状
- ★ 人均代码改动量（新增/删除堆叠条形）
- ★ 高频变更文件 Top（按改动行数 / 提交数双口径，可排序）
- 单文件归属（谁对该文件改动最多，v2）

#### F. 提交内容（Commits）
- ★ 提交类型分布（`feat/fix/refactor/docs/perf/test/chore/style/other`，随口径）
- ★ 提交规模分桶（按单次改动行数分桶）
- ★ 巨型提交 Top N（按改动行数）
- 关键词 / 词云（v2）

### 3.4 动态筛选
- **FR-7**：全局筛选器，作用于所有 Tab 与图表：
  - 时间范围：预设档位（全部 / 近 7 天 / 近 1 月 / 近 3 月 / 近 1 年）+ 自定义起止日期
  - 人员多选（默认全员，支持全选/清空）
  - 提交类型多选
  - 关键字（按提交信息模糊过滤）
- **FR-8**：任一筛选变化即时重算（客户端 JS，无二次请求）。
- **FR-9**：「重置」一键还原。
- **FR-10**：顶部展示统计摘要（统计分支 · 时间范围 · 提交数 · 人数 · 新增/删除行数）。
- **FR-11**：分支在报告中仅作标注与清单展示，不可切换；分析其他分支需重新生成并按需选择。

### 3.5 结果呈现（界面，Tab 结构）
- 全局置顶：仓库名 + 统计分支标注 + KPI 卡片 + 筛选栏 + 统计口径切换 + 摘要。
- 主体为 6 个 Tab（见 §4），切 Tab 只显示该分类图表，避免一页堆砌。
- 表格支持列排序；空态友好；图表标题随统计口径动态标注单位。

### 3.6 输出形态
- ★ 输出单个自包含 HTML，内联 `commits.json` 与 ECharts，离线可开、可分享。

## 4. 界面布局（Tab 线框）

```
┌───────────────────────────────────────────────────────────────┐
│ Header  仓库名/路径 · 生成时间 · 数据 N 条                     │
├───────────────────────────────────────────────────────────────┤
│ KPI：总提交 | 贡献者 | 新增行 | 删除行 | 净增行 | 活跃天数      │

│ 筛选栏：[口径 提交次数|代码行数] 时间▾ 人员(chips) 类型(chips)  │

│ [总览] [时间] [人员] [分支] [代码行数] [提交内容]  ← Tab 切换  │
├───────────────────────────────────────────────────────────────┤
```

各 Tab 内容规划：

| Tab | 内容 |
|---|---|
| 总览 | 趋势折线（口径切换）+ 提交热力图 |
| 时间 | 星期分布 + 小时分布 |
| 人员 | 排行表（可排序）+ 贡献占比 + 多人堆叠趋势 |
| 分支 | 统计分支标注 + 分支清单（参考，可排序） |
| 代码行数 | 净增行趋势 + 文件类型增删 + 人均改动量 + 高频文件 Top |
| 提交内容 | 类型分布 + 规模分桶 + 巨型提交 Top |

## 6. 技术方案（简述）

| 层 | 方案 |
|---|---|
| 右键集成 | 注册表 `Directory\shell` + 入口脚本，`%1` 传目录 |
| 采集 | `git log --numstat` → JSON（优先 PowerShell 零依赖） |
| 报告生成 | 读 JSON → 注入 HTML 模板 → 单文件输出 |
| 前端渲染 | 原生 HTML/CSS/JS + ECharts（内联，保证离线） |
| 筛选/口径 | 全在浏览器内存完成（万级提交内毫秒级） |

## 7. 假设与待确认

1. **系统**：v1 仅 Windows；报告 HTML 跨平台可看。
2. **右键条件显示**：v1 目录上始终显示 + 脚本判断 `.git`；条件显示需编译扩展（v2）。
3. **统计口径**：预选单分支、按 author 时间；未显式选择分支时的默认值、以及是否改按 commit 时间，待评审。
4. **作者归属**：默认按 `author`；cherry-pick/rebase 差异 v1 忽略。
5. **行数口径**：改动 = 新增+删除；净增 = 新增−删除；二进制/空行按 `--numstat` 原值，不额外处理。
6. **图库**：ECharts 内联（约 1MB），单文件离线共享。
7. **运行时**：优先 PowerShell；复杂解析可换 Node。

## 9. 原型说明

`原型.html` 为 M0 交付的可交互原型：
- 内置模拟数据（8 人、12 个月、约 182 次提交），演示全部 v1 维度；
- **Tab 分类**：总览 / 时间 / 人员 / 分支 / 代码行数 / 提交内容；
- **双统计口径切换**：提交次数 ↔ 代码行数；
- **分支维度**：单分支统计（预选 develop），报告标注统计分支 + 分支清单参考（不支持切换）；
- **时间范围**：预设档位 + 自定义起止日期；
- 筛选栏（时间 / 人员 / 类型 / 关键字）与表格排序均真实可交互；仅作界面示意，不接真实 git 数据。
